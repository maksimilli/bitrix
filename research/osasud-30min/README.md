# OSASUD: обрезанные записи и исследовательский ноутбук

**Большой файл 3,28 ГБ не нужен.** Здесь настоящие исходные сигналы по 30 минут
для 30 пациентов — суммарно 15 часов. Значения и врачебные метки не синтезированы
и не подменены. Все результаты пересчитаны только на этой обрезанной выборке.

## Происхождение и содержимое

Статья: https://pmc.ncbi.nlm.nih.gov/articles/PMC9018698/ .
DOI данных: https://doi.org/10.6084/m9.figshare.19214289.v1 . Лицензия исходных данных: CC0.
Проверенный MD5 полного оригинала: `b9ed560f4abf6100ce02cfc7cb0c121f`.
Контрольные суммы передаваемых файлов находятся в `SHA256SUMS`.

В архиве — `patient_1.npz` … `patient_30.npz` и manifest.json с правилом выбора
и исходными номерами строк. Каждый файл содержит signal_pleth (1800×80),
PSG_Flow (1800×20), event, timestamp_datetime, monitor_HR, source_row и patient.
monitor_HR перенесён из исходного HR(bpm), рассчитанного по ЭКГ; он используется
только для проверки пульса, а не как вход классификаторов.

Выбор: первый по времени непересекающийся 30-минутный блок с >=15 минутами,
прошедшими заранее заданный QC; если такого нет — первый блок. Ни event, ни
успех модели при выборе записей не используются. Выборка смещена по качеству
и времени ночи; она не представляет целые ночи. Иллюстрации с событиями
выбираются отдельно, без изменения обучающей или тестовой выборки.

## Метод и ограничения

Сравниваются PPG, flow-only и PPG+flow. Внешний GroupKFold(5) полностью разделяет
пациентов. Внутренний GroupKFold(3) выбирает C, строит OOF-оценки для Platt-калибровки
и выбирает порог по F1. Обучаемая предобработка и class balancing ограничены train-фолдами.
Фиксированные локальные фильтры и признаки вычисляются независимо внутри каждого окна.

После QC: 843 окна; бинарная задача APNEA>=10 секунд за минуту против целой минуты
NONE: 654 окна, включая 72 положительных, 30 пациентов. Гипопноэ и неоднозначные
окна исключены из бинарной оценки, но сохраняются в исходных данных.
Публикуются вероятности, ROC-AUC, average precision, Brier, калибровка,
условные 95% CI через 500 bootstrap-выборок пациентов и коэффициенты моделей.
См. metrics.csv и cluster_bootstrap_CI.csv.

Это исследовательская классификация минут, не AASM-скоринг, AHI или клинический
диагноз. Носовой поток не эквивалентен всем требованиям к датчикам стандартного
скоринга; гипопноэ требует дополнительных критериев. Согласие частоты пульса
с HR(bpm) не подтверждает правильность каждого пика. Морфологические Tp, App,
ST, DT, Smax, E(Tp) не реализованы и не заявляются. Разрывы прогнозов не закрываются,
короткие интервалы не удаляются. Нужна независимая внешняя валидация.

Проверено выполнение всех восьми ячеек в отдельной пустой папке без большого Pickle.
Пиковая память проверочного процесса — около 442 МБ; в другой среде она может отличаться.
